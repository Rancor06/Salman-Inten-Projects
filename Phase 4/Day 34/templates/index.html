📡 Projects REST API

A simple in-memory REST API built with Flask — Day 34 Internship Task

Available Endpoints

Method Endpoint Description
GET /projects Get all projects
GET /projects/<id> Get a single project by id
POST /projects Create a new project (JSON body: title, description, tech)
PUT /projects/<id> Update an existing project
DELETE /projects/<id> Delete a project

This page is plain HTML for humans. The endpoints above return JSON, for programs.
